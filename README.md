# Roller Coaster Exploratory Data Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on a Roller Coaster Database. The analysis focuses on understanding the characteristics, distributions, relationships, and trends present in the dataset.

## Objectives

- Understand the structure of the roller coaster dataset.
- Analyze roller coaster speed and height distributions.
- Explore manufacturers and locations.
- Analyze roller coaster introduction trends over the years.
- Identify the fastest roller coasters.
- Study relationships between numerical features using correlation analysis.

## Dataset

The dataset contains information about roller coasters, including:

- Roller coaster name
- Location
- Manufacturer
- Year introduced
- Type
- Speed
- Height
- Number of inversions
- G-force

The dataset contains **1,087 roller coasters and 56 attributes**.

## Exploratory Data Analysis

The following analyses were performed:

1. Dataset inspection and statistical summary
2. Missing-value and duplicate analysis
3. Speed distribution
4. Top manufacturers
5. Height distribution
6. Height vs. speed relationship
7. Correlation analysis
8. Correlation heatmap
9. Top roller coaster locations
10. Roller coasters introduced over the years
11. Top 10 fastest roller coasters
12. Average speed by roller coaster type

## Key Findings

- The dataset contains 1,087 roller coasters with 56 attributes.
- No duplicate rows were found in the dataset.
- Height and speed have a strong positive correlation of approximately 0.83.
- Formula Rossa has the highest recorded speed in the dataset at 149.1 mph.
- Average speed varies across different roller coaster types.
- The dataset shows differences in roller coaster distribution across manufacturers, locations, and years of introduction.

## Conclusion

The exploratory analysis provided useful insights into the characteristics and relationships within the roller coaster dataset. Visualizations and statistical analysis helped identify patterns in speed, height, manufacturers, locations, coaster types, and introduction years.

The analysis demonstrates how Exploratory Data Analysis can be used to understand a dataset and identify meaningful patterns before applying further statistical or machine learning techniques.
